# Контракты ФД

Калькулятор госконтрактов на frudom.ru/contracts: загружаете файл закупки (его делает ChatGPT/Claude, формат — `FORMAT.md`), сайт сам подставляет закупочные цены с сайта документов и считает прибыль при любом снижении.

| Файл | Что это | Куда вставлять |
|---|---|---|
| `Code.gs` | скрипт таблицы «Контракты ФД» | Google Таблица → Расширения → Apps Script |
| `app.js` | страница (оформление и логика) | никуда, Tilda берёт его сама с GitHub Pages |
| `tilda-block.html` | короткий код для Tilda | блок T123 «HTML-код» на frudom.ru/contracts |

## Установка

### 1. Таблица и скрипт
1. Создайте Google Таблицу «Контракты ФД».
2. «Расширения» → «Apps Script». Удалите всё, что там есть, вставьте содержимое `Code.gs`, нажмите «Сохранить».
3. Слева «Сервисы» → «+» → выберите **Drive API** → «Добавить». Без этого не читаются файлы .doc, .xls и PDF.
4. Обновите вкладку с таблицей. Появится меню «Контракты ФД» → «1. Первая настройка». Google попросит разрешения — согласитесь.
5. На листе «Настройки» заполните: ключ бота Макс, ключ ИИ, ссылку на таблицу «Документы ФД». Пароль для страницы уже придуман — можно поменять.
6. В Apps Script: «Развернуть» → «Новое развертывание» → тип «Веб-приложение» → «Запуск от имени: я», «У кого есть доступ: все» → «Развернуть». Скопируйте адрес (заканчивается на `/exec`).
7. Меню «Контракты ФД» → «Проверить бота и ключ ИИ».

### 2. Страница
1. GitHub → репозиторий → Settings → Pages → Branch: `main` → Save.
2. Tilda → frudom.ru/contracts → блок T123 → вставьте `tilda-block.html`, заменив `ВСТАВЬТЕ_АДРЕС` на адрес из шага 6 → опубликуйте страницу.

### 3. Бот в Максе
1. В Максе найдите @MasterBot → создайте бота → скопируйте ключ в лист «Настройки».
2. Напишите своему боту первым («Привет») — он запомнит, что выжимки нужно слать вам.
3. Пересылайте боту сообщения тендерщика и архивы. Через 1–3 минуты придёт выжимка.

Пока бота нет, контракты можно добавлять на странице кнопкой «Добавить».

## Обновление до калькулятора (18.11.2026)
1. Вставить новый `Code.gs` целиком → «Сохранить» → «Развернуть» → «Управление развертываниями» → карандаш → «Новая версия» → «Развернуть».
2. Страница обновится сама. Лист «Калькулятор» создастся сам при первом сохранении расчёта.
