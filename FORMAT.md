# Файл закупки для калькулятора (`frudom-contract-v1`)

Его делает ChatGPT, Claude или Grok из документов закупки. Файл загружают на frudom.ru/contracts
(кнопка «Выбрать файл», перетащить файл или «Вставить текст» — можно вставить ответ ИИ целиком).

```json
{
  "schema": "frudom-contract-v1",
  "number": "0848300069526000429",          // номер закупки
  "title": "Поставка продуктов питания для садов",
  "customer": "МБОУ «Гимназия № 2»",
  "nmck": 3606124.62,                        // НМЦК, руб.
  "tax_percent": 8,                          // налог с выручки, %
  "logistics": 150000,                       // логистика на весь контракт, руб. (можно 0)
  "deadline": "2026-11-26T10:00:00+03:00",   // окончание подачи заявок
  "url": "",                                 // ссылка на закупку (необязательно)
  "items": [
    { "name": "Крупа гречневая", "quantity": 430, "unit": "кг", "unit_price": 63.25, "purchase_price": null,
      "note": "коротко: фасовка, сорт",                 // одна строка под названием
      "spec": "полный текст требований ТЗ к товару" }  // раскрывается кнопкой «Требования ТЗ»
  ],
  "info": {                                           // кнопка «Описание» (всё необязательно)
    "summary": "3–5 предложений: что, кому, как возить, как платят",
    "verdict": { "level": "ok|care|bad", "text": "главный вывод" },
    "term": "с подписания по 31.05.2027",
    "facts": [ { "k": "Закон", "v": "223-ФЗ" }, { "k": "Обеспечение договора", "v": "5% — 128 404 ₽" } ],
    "flags": [ { "level": "red|yellow|green", "title": "до 60 знаков", "why": "почему важно и что делать" } ],
    "points": [ { "name": "Столовая № 1", "address": "Москва, Новочеремушкинская улица, 69", "note": "e-mail для заказов", "lat": null, "lng": null } ],
    "sections": [ { "title": "Как проходит поставка", "items": ["пункт", "пункт"] } ]
  }
}
```

- `unit_price` — цена за единицу из НМЦК (обоснования цены). `purchase_price` — моя закупочная цена, если известна, иначе `null`.
- Закупочные цены сайт подставляет сам из «Документы ФД» (склад, закупки, «Закупочные цены», «Цены поставщиков»).
  Цена из файла важнее — сайт её не меняет.
- Сайт сам добавляет в файл свои поля (`cut`, `src`, `updated`…) — при повторной загрузке они не мешают.
- `points`: координаты можно не писать — сайт найдёт адрес на карте сам (OpenStreetMap) и запомнит.
- `flags`: red — может принести убыток или сорвать контракт; yellow — заложить в цену и не забыть; green — плюсы.
- Принимается и старая карточка `"fdc": 1` (поле `pos`) — переводится в этот формат.

## Промпт для ChatGPT / Grok / Claude

> Прочитай все документы закупки. Сделай JSON строго в формате frudom-contract-v1 (описание формата ниже) и дай файл `contract-<номер>.json`.
> items — все позиции из обоснования НМЦК: name, quantity, unit (кг, л, шт.), unit_price, purchase_price null, note (одна строка: фасовка/сорт),
> spec — полный текст требований ТЗ к этой позиции (как в документе, без сокращений).
> info: summary; term — до какого числа действует контракт (дата дд.мм.гггг; выводится наверху расчёта); verdict (ok/care/bad + вывод); facts — закон, способ, площадка, только СМП, даты подачи и итогов, обеспечение заявки и договора (в рублях),
> срок договора, сроки и время поставки, оплата, штрафы, пени, остаточный срок годности, упаковка, документы с товаром;
> flags — все подводные камни (противоречия между документами, жёсткие сроки, национальный режим/запрет импорта, транспорт, приёмка, брак, штрафы, оплата);
> points — все адреса доставки (name, address с городом, note — контакты/часы); sections — порядок поставки, что приложить к заявке, контакты заказчика.
> Только то, что есть в документах. Сумма quantity × unit_price должна сходиться с НМЦК.
