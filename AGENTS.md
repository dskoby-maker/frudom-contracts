# AGENTS.md — «Контракты ФД»

Владелец — Даниил (Frudom), программировать не умеет: отвечать по-русски, просто, по шагам.

## Как устроено
- **Макс** → бот (Bot API, `platform-api.max.ru` / `platform-api2.max.ru`, опрос `GET /updates` раз в минуту из триггера `tick`).
- **`Code.gs`** — скрипт Google Таблицы «Контракты ФД». Листы: «Настройки» (ключи, пароль — в коде секретов нет), «Контракты» (строка = закупка; колонки `brief` и `data` — JSON карточки).
  - Сообщение и архив связываются по номеру закупки (`regNumber` в ссылке ↔ `Documents_<номер>.zip`), иначе — по чату и времени (`attachFile_`).
  - Чтение файлов: `.docx`, `.html` — сами; `.doc`, `.xls(x)`, PDF, сканы — через Drive API (преобразование в Google Docs/Sheets, `viaDrive_`); пустой PDF уходит в ИИ как документ.
  - ИИ (Claude API, инструменты `card` и `positions`, два запроса разом через `fetchAll`): выжимка — модель из настроек, товары — `claude-haiku-5-5`.
  - Закупочные цены — из таблицы «Документы ФД», самая свежая по товару из «Закупочные цены», «Склад: партии» и «Закупки» (`loadCosts_`). Прибыль: выручка − закупка − налог 8% с выручки, **НДС не вычитается** (`money_`).
  - Точки доставки — `Maps.newGeocoder()`.
  - Веб-приложение: `doPost` → `api_` (list, get, decide, note, redo, del, add, import, prices), пароль в каждом запросе.
  - (до 18.11.2026) **Путь с карточками:** владелец присылает zip в чат Claude, Claude делает файл карточки по `CARD_FORMAT.md`,
    владелец загружает его на сайте («Добавить» → `import_`). Если ячейка «Ключ ИИ» пуста, автоматический разбор не запускается
    (`processNext_` сразу выходит), бот только заносит контракты в список.
- **`app.js`** (VER 5, с 18.11.2026) — **калькулятор контрактов** на главной frudom.ru/contracts (и `calculator.html`, `index.html` на GitHub Pages). Без сборки и зависимостей.
  - Загружается файл закупки `frudom-contract-v1` (формат и промпт для ИИ — `FORMAT.md`): выбор файла, перетаскивание на страницу или «Вставить текст» (ответ ИИ целиком, JSON вырезается сам).
  - Расчёт: выручка по позициям × (1 − снижение) − налог 8% с выручки − закупка − логистика. **НДС не вычитается.** Порог «без убытка» (максимальное снижение) и минимальная цена — когда заполнены все цены.
  - Закупочные цены: действие `prices` (свои — `loadCosts_`, поставщиков — `loadVend_` из листа «Цены поставщиков» «Документы ФД»). Подбор по словам названия (`stems/score/suggest/fill`): уверенное совпадение при той же единице ставится само с жёлтой подписью «Проверьте», выбор в окне запоминается (`fdc-match-v1`). Цены, взятые с сайта, обновляются до свежих при каждой загрузке.
  - Хранение: браузер (`fdc-calc-v1`, переносит старый `fdc-tenders-v1`) + лист «Калькулятор» (`clist/cput/cdel`), побеждает более свежий `updated`.
  - Пароль и адрес скрипта — как раньше (`fdc-pass`, `fdc-api`, `window.FDC_API`); без них калькулятор работает, но без цен и без синхронизации.
  - Старые карточки с ИИ, карта и список контрактов из бота **убраны со страницы** (код в `Code.gs` остался, но страница его не вызывает).

## Правила
- После изменения `Code.gs` увеличить `CODE_VER` и напомнить про «Новая версия» развертывания.
- Любой текст из таблицы и от ИИ на странице — только через `esc()`.
- Каждое изменение коротко записывать сюда, в «Журнал».
